# Arcra - Simple, Double-Entry Bookeeping

## Expected Envrionmental Variables

| Variable Name | Purpose | Type |
| --- | --- | --- |
| USERNAME | The username used for login on this instance. | UTF-8 String |
| PASSWORD | The password used for login on this instance. | UTF-8 String |
| COOKIEKEY | A random 64 byte key used for cookie encryption. Can be generated using `openssl rand -base64 64`. | Base64-encoded 64 byte key |
